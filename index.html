《七日回声》（以下简称“本游戏”）由比特回声工作室（以下简称“我们”）开发并运营。我们深知个人信息对您的重要性，将按照法律法规与业界标准保护您的个人信息。

一句话概括：本游戏是一款单机文字冒险游戏。您不登录也能完整游玩；我们不收集您的手机号、身份证号、位置、通讯录、相册、麦克风与摄像头信息；游戏进度仅保存在您的设备本地，不会上传到我们的服务器。

一我们如何收集和使用您的个人信息

1. 基本说明

本游戏为单机游戏，核心玩法不依赖账号。您可以直接以“游客”状态开始游玩，此状态下我们不收集任何可识别您个人身份的信息。

2. TapTap 账号登录（可选）

当您主动点击“TapTap 登录”时，我们通过 TapTap 开放平台 SDK 获取以下信息，用于创建游戏账号并将游戏进度与账号绑定：

  • TapTap 用户标识（unionid / openid）——用于区分不同用户、绑定存档
  • TapTap 昵称与头像——用于在游戏内展示您的登录状态

您可以选择不登录。不登录时，游戏进度仅保存在本机，更换设备或卸载重装后将无法恢复。

3. 设备与运行信息

为保障游戏正常运行、适配机型与排查崩溃，本游戏及所接入的第三方 SDK 会获取以下信息：

  • 设备型号、操作系统版本、屏幕分辨率、系统语言
  • 设备标识符（如 Android ID；在支持的系统上为匿名化标识）
  • 网络类型、IP 地址、应用版本号、崩溃与异常日志

我们不会收集您的精确地理位置、通讯录、短信、相册、麦克风与摄像头内容。

4. 游戏进度数据

游戏进度（天数、数值、道具、成就、结局解锁情况、已读剧情标记）使用设备本地存储（localStorage）保存在您的设备上。我们不会将该数据上传至服务器。您可以在游戏内「菜单 → 放弃本次坠落（清档重开）」清除本地存档。

5. 权限调用情况

本游戏仅申请以下系统权限，均用于实现对应功能，您可以在系统设置中随时关闭：

权限名称调用目的是否必须可否关闭
网络访问（INTERNET）TapTap 账号登录、必要的服务端通信否（不登录时无需）可
网络状态（ACCESS_NETWORK_STATE）识别网络是否可用，避免登录时无响应否可

本游戏不申请通讯录、短信、位置、相机、麦克风、存储读写等权限。

6. 实名认证与防沉迷

本游戏通过 TapTap 平台的云游戏 / 渠道服务分发，实名认证与防沉迷由 TapTap 平台按其规则统一提供。我们自身不收集您的姓名与身份证件号码。相关个人信息处理规则请参见 TapTap 平台的隐私政策。

7. 广告服务

本游戏当前版本未接入第三方广告服务，不会向您推送个性化广告。游戏内的“向回声祈愿”等入口目前仅在本地模拟展示，不涉及任何广告数据收集。若未来版本接入广告服务，我们会在更新本政策、并在游戏内以显著方式征得您的同意后再行实施。

8. 我们如何使用这些信息

  • 提供游戏核心功能（剧情推进、存档、成就与结局记录）
  • 完成账号登录与存档绑定
  • 保障服务安全与稳定，排查崩溃与异常
  • 在去除身份识别信息后进行整体统计分析（如留存、通关率），用于改进游戏体验

我们不会将您的个人信息用于本政策未载明的其他用途；如需变更用途，将另行征得您的同意。

二我们如何保存您的个人信息

  • 存储地点：我们在中华人民共和国境内收集和产生的个人信息，存储于境内。本游戏不向境外传输您的个人信息。
  • 存储期限：账号标识信息在您的账号存续期间保存；您注销账号或要求删除后，我们将在 15 个工作日内删除或匿名化处理。
  • 本地数据：游戏进度保存在您的设备上，仅在您主动清除或卸载应用时删除，我们无法远程访问。

三我们如何使用 Cookies 等技术

本游戏为本地运行的移动应用，不使用 Cookies。我们仅在您的设备本地使用 localStorage 保存游戏进度与偏好设置（音乐/音效开关），该数据不会离开您的设备。

四我们如何共享、转让、公开披露您的个人信息

  • 共享：除本政策列明的第三方 SDK 与法律法规要求外，我们不会向任何第三方共享您的个人信息。我们不会出售您的个人信息。
  • 转让：如发生合并、收购或资产转移，我们将要求承接方继续受本政策约束，否则将重新征得您的同意。
  • 公开披露：我们不会公开披露您的个人信息，除非获得您的明示同意或法律法规另有规定。
  • 法定情形：根据法律法规、司法或行政机关的强制性要求，我们可能披露必要信息。

五第三方产品或服务如何获得您的个人信息

为实现登录与运行保障，本游戏接入了以下第三方 SDK。其在为您提供服务的过程中可能会收集相关信息，具体以各 SDK 运营方的隐私政策为准：

SDK 名称提供方使用目的可能收集的信息
TapSDK（含 TapTap 登录、基础服务） 易玩（上海）网络科技有限公司 TapTap 账号登录、账号安全与风控、崩溃分析 TapTap 用户标识、昵称、头像、设备型号与系统版本、设备标识符、IP 地址、网络类型、应用版本、崩溃日志

上述 SDK 的隐私政策请参见 TapTap 开放平台公示内容。我们已对 SDK 进行安全评估，并要求其按照法律法规处理您的个人信息。

此外，当您通过 TapTap 平台下载、更新或以云游戏方式运行本游戏时，TapTap 平台会按其自身隐私政策处理您的相关信息，该部分处理行为不由我们控制。

六我们如何保护您的个人信息

  • 我们采用符合业界标准的安全措施（传输加密、访问控制、最小必要原则）保护您的信息。
  • 我们仅保留实现功能所必需的信息，并在达到保存期限后删除或匿名化。
  • 我们的员工与外包人员无权访问您的个人信息，除非为完成特定服务且经严格授权。
  • 如不幸发生个人信息安全事件，我们将按照法律法规要求及时告知您，并向主管部门报告。

请注意：互联网环境并非百分之百安全。请您妥善保管设备与账号，避免在非受信设备上登录。

七您如何管理您的个人信息

您对个人信息享有以下权利，可通过本政策末尾的联系方式与我们联系，我们将在 15 个工作日内响应：

  • 访问与更正：您可以在游戏内「菜单」查看当前登录账号信息；如需更正，可注销后重新登录。
  • 删除：您可以通过「菜单 → 放弃本次坠落（清档重开）」清除本地存档；如需删除账号关联信息，可联系我们处理。
  • 撤回同意：您可以在系统设置中关闭网络权限，或在游戏内退出登录，撤回对相应信息处理的授权。
  • 注销账号：您可以在游戏内「菜单 → 账号 · 切换」退出当前账号，或联系我们注销与账号关联的游戏数据。
  • 投诉举报：如您认为我们的个人信息处理行为损害了您的合法权益，可向我们投诉，也可向网信、市场监管等主管部门举报。

八我们如何处理未成年人的个人信息

  • 本游戏面向一般用户。若您是未满 14 周岁的儿童，请在监护人的陪同与同意下阅读本政策并使用本游戏。
  • 我们不会主动收集未成年人的个人信息；登录功能需由您主动发起。
  • 若监护人发现我们在未获同意的情况下收集了儿童的个人信息，请联系我们，我们将尽快删除。
  • 本游戏的实名认证与防沉迷措施由 TapTap 平台统一提供，我们不会存储未成年人的身份信息。

九本政策如何更新

我们可能因业务调整或法律法规变化更新本政策。更新后我们会在本页面公布新版本并更新“更新日期”；如涉及处理目的、方式的重大变更，我们将在游戏内以显著方式通知您，并重新征得您的同意。

本政策的历史版本可在本页面底部查看版本号。您继续使用本游戏，即表示同意更新后的政策。
